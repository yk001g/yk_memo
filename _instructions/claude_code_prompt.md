# タスク：yk_memoサイトに /salon/ ページを新設

スマホ・わいわいサロン（片倉台自治会主催・yk_memoが運営講師として関わる月例会）の紹介ページを、yk_memoサイト内に新設してください。

## 前提

- yk_memoサイトは Astro + TypeScript + Content Collections で構築済み
- 既存ページ：`/`, `/notes/`, `/skills/`, `/about/`
- 新規追加：`/salon/`
- デザインシステム（カラー、タイポ、コンポーネント）は既存のものを完全継承
- 本文テキストは添付の `salon_page_content_final.md` を参照（ヒーロー、サロンとは、6つの学びのテーマ、哲学、関連記事、CTA、フッター情報）

## 実装内容

### 1. 新規ページ作成：`src/pages/salon/index.astro`

セクション構成（添付MDの順番どおり）：

1. **ヒーロー**：「質問、大歓迎。みんなで学ぶ、スマホの『？』解決の場。」
   - 既存ページのヒーロースタイルを踏襲（写真背景は使わない／プレーンなタイポグラフィ）

2. **サロンとは**：3段落の本文（添付MD「サロンとは」をそのまま）

3. **学びの6つのテーマ**：カードグリッド表示
   - 既存サイトのカードコンポーネントがあれば再利用
   - レスポンシブ：デスクトップ3列／タブレット2列／モバイル1列
   - アイコンは付けず、見出し＋本文のみのシンプルな構成（フォント階層で区別）

4. **サロンの哲学**：blockquote として表示
   - 「主役は『懇談タイム』。学び合い、教え合う、私たちの時間。」を引用
   - その下に補足の段落を続ける

5. **関連する記事**：Astro Content Collections で実装
   ```ts
   const salonNotes = await getCollection('notes', ({ data }) =>
     data.tags?.includes('salon') && !data.draft
   );
   ```
   - 該当記事がない場合は「準備中です」と表示
   - 既存のNotes一覧と同じカードスタイルを使用

6. **CTAブロック：最新は公式ページへ**
   - 見出し：「最新は公式ページへ」
   - 公式URL：`https://sites.google.com/view/k...`（※YKに正確なURLを聞いてから差し込む。仮のままにせず空欄で待つこと）
   - リンク属性：`target="_blank"` `rel="noopener noreferrer"`
   - ボタン右上に外部リンクアイコン（↗）を表示
   - 補足文：「初めての方も大歓迎。お使いのスマートフォンと、『知りたい』『聞きたい』という気持ちがあれば十分です。」

7. **フッター情報**（ページ末尾、目立たない小さめの文字色）：
   ```
   主催：片倉台自治会・福祉委員会・福祉ネットワーク
   運営・講師：yk_memo（協力メンバー数名）
   ```

### 2. ナビゲーション追加

共通ナビコンポーネント（おそらく `src/components/Nav.astro` か `src/layouts/` 配下）に「サロン」項目を追加。

- ラベル：**サロン**（日本語表記。英語混在で問題ない既存サイトの方針に合わせる）
- リンク先：`/salon/`
- 配置：`Skills` と `About` の間
- 現在ページ判定（ariaCurrent等）は既存の他項目と同じ方式に揃える

### 3. About ページ改修

`src/pages/about.astro`（または対応するファイル）の活動紹介セクションに、以下のような段落を追加：

> 八王子・片倉台で月1回、シニア向けのスマホ相談会「[スマホ・わいわいサロン](/salon/)」を運営・講師として続けています。

- リンクは内部リンク（`/salon/`）
- 既存のAbout本文の流れを壊さない位置に挿入

### 4. Notes側の対応

`src/content/config.ts` を確認し、Notesコレクションのスキーマに `tags` フィールドが定義されているか確認。

- 既に `tags: z.array(z.string()).optional()` があれば変更不要
- なければ追加してください

`/salon/` ページから Notes を取得する際は、上記スキーマに依存。

### 5. 実装後の確認

- `npm run dev` で起動
- 以下4つのURLが200で応答することを `curl` で確認：
  - `http://localhost:4321/salon/`
  - `http://localhost:4321/about/`
  - `http://localhost:4321/notes/`
  - `http://localhost:4321/`
- ナビゲーションに「サロン」が表示され、各ページから遷移できるか目視確認
- レスポンシブ確認：モバイル幅（375px）でも崩れないか

## デザイン上の注意点

- **既存サイトのトークンに完全準拠**。新しい色やフォントを足さない
- 写真は使わない（PDF素材の権利確認が未了のため）
- アイコンも今回は付けない。タイポグラフィの階層だけで構成する
- カードには影をつけず、ボーダーのみで区切る（既存サイトのスタイルに合わせる前提）
- 6テーマカードのうち①〜⑥の番号は **小さめ・控えめに**（メインは見出し）

## 公式URLについて

CTAの公式URL `https://sites.google.com/view/k...` は仮置きです。
**実装前にYKに正確なURLを確認してください。** URL未確定のままダミーURLでビルドしないこと。
